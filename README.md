# Locs by Nya - Booking Site

A simple, modern booking page for loctician services built with Next.js and Tailwind CSS.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- Clean, modern booking form
- Responsive design
- Service selection dropdown
- Date and time pickers
- Form validation
- Success/error messaging

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
